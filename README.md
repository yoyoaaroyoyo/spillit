This project is the first step towards "Absolute Privacy" for me.

  **About**
Spillit is a privacy-focused notes-taking webapp (texting, journaling and browsing in the future) designed to store your info locally in YOUR computer. (I may add cloud storage in the future.)
Spillit can be used for notes taking, journaling, writing down experiences and memories and much more. It is designed using HTML, CSS and JavaScript currently.
